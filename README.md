# Diet Recommender 🥗
A web application that generates personalized diet plans based on user's health metrics and dietary preferences.

##### Live Demo:  [ https://diet-recommender-opal.vercel.app/](https://diet-recommender-opal.vercel.app/)

## 📝 Description
The Diet Recommender is an intuitive tool designed to help users achieve their health and fitness goals, whether it's weight loss, weight gain, or weight maintenance. By inputting key information such as age, weight, height, and dietary choices, users receive a customized 7-day meal plan.


### ✨ Features

* **Personalized Inputs:** Takes user data like age, weight (kg), height (cm), and primary goal.
* **Dietary Preferences:** Allows users to choose between vegetarian and non-vegetarian meal plans.
* **Dynamic Plan Generation:** Instantly creates a structured 7-day diet chart (Breakfast, Lunch, Dinner).
* **Healthy Lifestyle Tips:** Provides additional actionable tips to support the user's health journey.
* **Responsive Design:** Fully functional and easy to use on both desktop and mobile devices.

### 🚀 How It Works

  1. **Navigate** to the website.
  2. **Fill in your details:** Enter your age, weight, height, and select your fitness goal.
  3. **Choose your diet type:** Select either "Vegetarian" or "Non-Vegetarian".
  4. **Click "Get Diet Plan":** The application will generate and display your personalized 7-day diet plan.
  5. **View Your Plan:** Scroll down to see the detailed meal chart and additional health tips.

### 🛠️ Technologies Used

This project is built with a modern web stack:

* **Frontend:** React.js (or Next.js)

* **Styling:** Tailwind CSS (or Material UI)

* **Deployment:** Vercel


## ⚙️ Getting Started (Running Locally)

To get a local copy up and running, follow these simple steps.

**Prerequisites**

* Node.js and npm installed on your machine.
  ``` bash
  npm install npm@latest -g
  ```
**Installation**

1. Clone the repo
   ```bash
   git clone [https://github.com/your-username/diet-recommender.git](https://github.com/your-username/diet-recommender.git)
   ```
2. Install NPM packages
   ```bash
   npm install
   ```
3. Start the development server
   ```bash
   npm start
   ```
4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
